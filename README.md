# EY Open Science AI & Data Challenge — Cooling Urban Heat Islands

## Summary
This project was developed for the EY Open Science AI & Data Challenge, focused on cooling urban heat islands. Participants use satellite and other geospatial data to build machine learning models that forecast city temperatures and identify heat hotspots to support planning of cooling interventions and resilient urban design. The challenge is open to EY people, university students, and early-career professionals, with recognition and prizes for top solutions. 


## Repository structure
Final_Notebook.ipynb
Contains the final model: data preprocessing, feature engineering, training, validation, and inference. Treat this as the end-to-end, reproducible pipeline that generates the submitted predictions and artifacts.

Answer_Questions.ipynb
Contains the final analysis: responses to the competition questions, exploratory data analysis, model evaluation, error analysis, limitations, and next-steps/impact discussion.

## How to use
Start in Final_Notebook.ipynb to investigate the model and outputs.

Read Answer_Questions.ipynb for the key model EDA that accompanies the submission.
